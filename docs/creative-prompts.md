# Creative asset brief — фото и видео

Все визуальные слоты на сайте и в личном кабинете сейчас — `PhotoSlot`
плейсхолдеры (`data-photo-slot="..."`, см. `src/components/ui/PhotoSlot.tsx`).
Ниже — точный бриф на каждый слот: что снять/сгенерировать и каким
промптом, если используется AI-генерация (Midjourney / DALL·E / Flux).

## Общий стиль

Премиальная пастельная эстетика: мягкий кремовый/бежевый/белый/блаш-розовый
фон, естественный дневной свет, домашняя (не студийная) кухня, тёплые тона,
неглубокая глубина резкости. Никакого стока — только кадры, которые выглядят
как реальная кухня реального человека.

**Базовый промпт-суффикс** для всех AI-генераций:
```
soft natural window light, warm pastel tones, shallow depth of field,
home kitchen setting, editorial food photography, no text, no watermark,
85mm lens look, --ar 4:5 --style raw
```

## Слоты и промпты

### `hero-main`
Готовый многоярусный торт крупным планом на кухонном столе, за ним слегка
размытая кухня. Женские руки в кадре (не лицо) поправляют последний
цветок из крема.
```
close-up of an elegant three-tier cream cake on a rustic wooden kitchen
table, woman's hands adjusting a buttercream flower, blurred cozy home
kitchen background, [base suffix]
```

### `author-portrait`
Портрет Марины Соколовой (основательницы) в фартуке на своей кухне,
тёплая улыбка, естественный свет, держит в руках торт или миксер.
Это должно быть настоящее фото автора — AI-генерация здесь не подходит,
только реальная фотосъёмка.

### `module-01-biscuit` … `module-08-business`
Восемь кадров — по одному на модуль программы (см. `modules` в
`src/lib/content/product.ts`), показанных в блоке «Программа» рядом с
открытым модулем аккордеона. Каждый — кадр процесса, соответствующий теме
модуля (бисквиты, кремы, начинки/ганаши, сборка и выравнивание,
украшение, капкейки/пирожные, чизкейки, торты на заказ).
```
close-up baking process shot matching the module topic, editorial style,
[base suffix]
```

### `testimonial-olga` / `testimonial-natalia` / `testimonial-irina` /
### `testimonial-svetlana` / `testimonial-yulia` / `testimonial-galina`
Портретный кадр 4:3 женщины 40-55 лет с готовым тортом на своей кухне,
искренняя улыбка, не постановочная. По одному уникальному фото на каждую
ученицу — соответствуют возрасту/городу, указанным в
`src/lib/content/product.ts`. Идеально — реальные фото учениц с их
согласия; если недоступны, AI-генерация с явным указанием "not a real
person, illustrative" в metadata.

## Видео

- **Промо-ролик на Hero** (опционально, 15-30 сек): монтаж из кадров
  процесса + готовых тортов под лёгкую музыку, без слов, с subtitles
  ключевых фраз ("500+ учениц", "4.9★").
- **40 уроков** — см. `product/video-scripts.md` для полного списка тем
  и покадрового сценария каждого урока.

## Логотип и favicon

Текущий `src/app/icon.tsx` и `src/app/opengraph-image.tsx` генерируются
программно (эмодзи 🍰 на бордовом фоне) — рабочий, но временный вариант.
При наличии готового логотипа — заменить на статический `icon.png` /
`opengraph-image.png` в `src/app/`.

## Чек-лист перед заменой плейсхолдеров

- [ ] Все 6 портретов учениц отсняты/сгенерированы
- [ ] Портрет автора — реальное фото
- [ ] Hero-фото торта в высоком разрешении (минимум 1600×2000)
- [ ] Все 8 фото модулей программы (`module-01-biscuit` … `module-08-business`)
- [ ] Единый цветокоррекция по всем фото (Lightroom-пресет или аналог)
- [ ] Логотип в векторе (SVG) для будущей замены emoji-иконки
